# Synthetic ProofAtlas append fixture

`synthetic_curated_proofatlas.jsonl` is fabricated test data. It contains no
problem text, metadata, identifiers, or attribution copied from ProofAtlas.
The fixture exists solely to test the frozen-curated-input contract of the
v1.8 append builder. Its `statement_provenance` attestation intentionally uses
the curator-authored-independent-normalization mode; it is not a template for
claiming rights to upstream source text.
